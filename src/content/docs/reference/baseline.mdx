Ubuntu Pro is optional for app development. The baseline records the support window so readers can judge whether a release is a reasonable target; it does not make Pro a requirement.

## Baseline is not minimum support

The baseline is the **tested reference environment**. It is not a claim that older releases are unsupported, and it is not a promise that every combination of components works together.

- Use the baseline when you need the current, validated target for examples, screenshots, and recommendations.
- Define a separate minimum-version policy when you ship a library or a package for an older LTS.
- Guard newer APIs at runtime when you support more than one release.
- A component can be newer than the baseline in a Flatpak runtime; record that difference in the manifest, not by rewriting this page.

## Updating the baseline

1. Update `src/data/baseline.json`.
2. Move `validated_on` to the review date and set `review_due` six months later.
3. Run `npm run check:baseline`.
4. Run `npm run build` and check the pages that link here.
5. Update the primary-source links if a source moved.
6. Commit the change and note the upstream release in the commit message.

The update is a normal OpenSpec change. It should explain which upstream release triggered it and which pages were re-checked.
